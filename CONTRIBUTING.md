# Contributing

Thanks for helping improve Tech Visuals 101.

## What to Contribute

Good contributions include:

- Fixing typos
- Reporting unclear explanations
- Improving file names or organization
- Suggesting missing topics
- Reporting duplicate or outdated visuals

## Content License

The materials in this repository are licensed under CC BY-NC-ND 4.0.

Because the license does not allow redistributed derivatives, please open an issue before submitting modified versions of the visuals themselves. Small metadata, documentation, and organization improvements are welcome through pull requests.

## Issues

When opening an issue, include:

- The file name
- What looks wrong or unclear
- The suggested correction, if you have one

## Pull Requests

Keep pull requests focused and easy to review. A small correction is better than a large mixed change.
